พิมพ์บาร์โค้ดติดแฟ้ม (Code 128)
บาร์โค้ดเป็นแบบ Code 128 เข้ารหัสเป็น ตัวอักษร เพื่อให้สแกนได้ถูกต้องแม้แป้นพิมพ์เป็นภาษาไทย (0001 = aaad) · เลขใต้บาร์โค้ดคือเลขแฟ้มสำหรับคนอ่าน · ป้าย “พิมพ์แล้ว” แสดงบนจอเท่านั้น ไม่ถูกพิมพ์ลงสติกเกอร์
ค้นหา / กรองแฟ้ม
